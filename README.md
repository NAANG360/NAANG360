## ◉ HOW I BUILD

I don't really have a neat little pipeline.

It's more like:

```text
        ┌──────────────────────┐
        │      RANDOM IDEA     │
        └──────────┬───────────┘
                   │
                   ▼
          ┌─────────────────┐
          │ "can I actually │
          │    build this?" │
          └────────┬────────┘
                   │
                   ▼
        ┌──────────────────────┐
        │ TERMINAL + BREADBOARD│
        └──────────┬───────────┘
                   │
              ┌────▼────┐
              │  BUILD  │
              └────┬────┘
                   │
          ┌────────▼────────┐
          │ works / explodes│
          └────────┬────────┘
                   │
                   ▼
              ┌─────────┐
              │  LEARN  │
              └─────────┘
```

Sometimes the explosion is electrical.

Sometimes it's a compiler.

Sometimes it's both.
